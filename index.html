¿Como funciona?

El sistema permite informar un problema tecnologico de manera simple y ordenada

1

Detecta el problema

Identifica si existe una falla en un computador, proyector, conexion WiFi u otro equipo

2

Realiza el reporte

Indica el tipo de problema, la ubicacion y explica brevemente que ocurrio

3

Se revisa la falla

El encargado puede revisar la información y gestionar una solucion
